# Algo Bot Telegram

Algo Bot — Telegram-бот для повседневной работы преподавателей с учебными группами, материалами и обратной связью.

## Возможности

- просмотр групп и расписания занятий;
- работа с учебными курсами и материалами;
- сбор и оформление обратной связи по ученикам;
- напоминания и фоновые задания;
- учёт пользовательской активности и рабочая аналитика;
- разграничение доступа преподавателей и администраторов;
- резервное копирование рабочих данных;
- единый информационный раздел для преподавателей.

## Как устроено

Основной контур написан на Python с использованием `python-telegram-bot` и работает через long polling. Обработчики сообщений и callback-запросов отделены от сервисов групп, материалов, обратной связи и аналитики.

Рабочее состояние хранится в SQLite, а справочные материалы — в JSON. Доступ к базе инкапсулирован в отдельных сервисах; резервные копии создаются через согласованный SQLite snapshot, поэтому бот может продолжать работу во время копирования.

Проект разделён на слой Telegram-интерфейса, доменные сервисы и инфраструктурные модули. Дополнительный веб-интерфейс реализован на FastAPI и Jinja2 поверх тех же сервисов, без дублирования бизнес-логики.
